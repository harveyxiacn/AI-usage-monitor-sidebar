# AI Usage Sidebar v0.5.0

## 中文

- 新增「会话」工作区：关联 Token 消耗与会话名称，区分原生标题、本地别名、需求摘录和默认名称；支持日期、项目、服务商筛选及后端分页。
- 按需查看原始提示词、助手输出、工具记录与轮次指标；显示父子会话关系、缓存输入、工具失败、重复调用和估算活跃时间。无法关联的指标明确显示未知。
- 新增按需 AI 深度评测：先预览并编辑发送内容，再通过自行配置的接口评估提示词、需求满足证据与效率。支持报告缓存、历史记录和人工修订，区分 AI 判断与用户确认。
- 加快大日志导入和统计查询：Codex 持久化增量读取位置，文件变更队列配合定期校验，查询缓存随数据和价格变化失效。
- 改善界面加载和刷新：按需加载仪表盘模块、复用图表、分页长列表，隐藏窗口减少轮询。

本地内容默认关闭；开启仅允许读取本机原始日志。AI 评测仅在主动发送后调用配置的服务，API Key 由环境变量提供。费用和活跃时间均为估算，AI 结论需要结合证据判断。

使用方法见 [会话分析说明](../SESSIONS.md)。Windows 提供 EXE/MSI，Linux 提供 AppImage/DEB/RPM，macOS 提供 Apple Silicon 和 Intel DMG。

## English

- Connect token usage to named sessions, with local aliases, native titles, labelled prompt excerpts, real pagination and date/project/provider filters.
- Inspect local prompts, responses, tools and linked turn metrics on demand. Parent and child agents retain separate usage; unknown attribution stays unknown.
- Evaluate prompts, requirement evidence and efficiency through an explicitly configured AI service. Review the exact editable preview before sending, reuse saved reports, and distinguish AI proposals from human revisions.
- Reduce repeated work with persisted Codex ingestion checkpoints, dirty-file scheduling, bounded query caches, lazy dashboard modules, reusable charts and paginated tables.

Local transcript access defaults off. Remote evaluation requires an explicit send; API keys come from a named environment variable. Token prices and activity measurements are estimates, and AI assessments are not independent proof of task completion.

See [Session analysis](../SESSIONS.md) for configuration, evidence limitations and local retention. Installers cover Windows x64, Linux x64, macOS Apple Silicon and Intel. Updater signatures authenticate updates; the applications remain without Windows Authenticode signing or macOS notarization.
