# AI Usage Sidebar v0.6.0

## 中文

- **提醒补全并可外发**：窗口越过警告/严重阈值时提醒（此前文档已承诺但未实现），另有月度预算 80%/100% 提醒、每周一摘要；可选 Webhook（通用 JSON、ntfy、Slack，仅 https）。新增专注/勿扰模式，可限时静音所有提醒并隐藏侧栏。
- **History 重做**：拆为"用量 / 配额 / 成本"三个子页。新增 KPI 环比、Token 构成与缓存命中率趋势、模型与推理强度构成、项目排行、热力图指标切换；配额周期峰值与撞限次数、"每 1% 配额约多少 token"、订阅价值对比（API 等价估算 ÷ 订阅价）。
- **会话洞察**：成本与时长分布、轮次×成本散点、最贵/最长/失败率最高/重复调用最多的会话、工具使用统计（只用工具名，不读内容）。
- **侧栏**：可在环下显示重置倒计时；越阈值与重置时的一次性动画；紧凑"迷你条"样式；预测虚线弧与"将耗尽"标记；分段收起把手；弹窗内 24 小时趋势线；上下边缘更宽的布局。键盘焦点、读屏标签和对比度全面改进。
- **托盘**：顶部显示各服务用量，图标按严重度着色，可直接显示百分比（macOS 菜单栏文字）；快速切换预设、专注模式、暂停轮询。Windows 上"自动"语言现在跟随系统界面语言。
- **设置**：分卡片、目录导航与搜索；分卡恢复默认；导入/导出与最近 5 版撤销；预设方案；快捷键录制；诊断信息一键复制；"隐私与网络"列出全部本地读取与外发请求。
- **新用户与更新**：首次运行向导、入门卡片（检测登录状态并给出登录命令）、更新后"新功能"说明、可跳过某个版本、下载进度。
- **集成**：`ai-usage-sidebar --print` 输出配额，可用于 Claude Code 状态栏、tmux、waybar（见 [STATUSLINE](https://github.com/harveyxiacn/AI-usage-monitor-sidebar/blob/main/docs/STATUSLINE.md)）；数据备份与恢复；命令面板（Ctrl/Cmd+K）；可分享的用量卡片图片。
- **服务商与预测**：新增实验性 OpenRouter（未经真实账号验证，默认关闭，密钥仅从环境变量读取）；百分比停滞时用 token 速率辅助预测。
- **稳定性**：日志目录出现或重建后自动恢复监听；配额历史按保留天数清理并降采样；令牌过期判定留出时钟余量并重读凭据；网络瞬时错误自动重试一次。

费用均为按 API 价格的估算，不代表订阅账单。

## English

- **Alerts that actually fire**: notifications when a window crosses the warning or critical threshold (documented before, but missing), monthly budget alerts at 80 % and 100 %, and a Monday summary. Optional webhook delivery (generic JSON, ntfy, Slack; https only). Focus mode silences every alert for a while and can hide the bar.
- **History, rebuilt**: Usage, Quota and Cost sub-views. KPI tiles with period-over-period change, token mix and cache-hit trend, model and reasoning-effort mix, project ranking, heatmap metrics; per-cycle quota peaks and limit hits, tokens per 1 % of quota, and subscription value (API-equivalent estimate vs. what you pay).
- **Session insights**: cost and duration distributions, turns × cost scatter, the most expensive, longest, most failing and most repetitive sessions, and tool usage (tool names only, never content).
- **Sidebar**: optional reset countdown under each ring, one-shot animations on threshold crossings and resets, a compact mini-bar style, a forecast arc with a run-out badge, a segmented collapsed handle, 24-hour sparklines in the popover and a wider layout on top/bottom edges. Keyboard focus, screen-reader labels and contrast were reworked throughout.
- **Tray**: per-provider usage at the top of the menu, a severity-coloured icon or the percentage itself (menu-bar text on macOS), and quick presets, focus mode and pause polling. On Windows, the "auto" language now follows the system display language.
- **Settings**: cards with an index and search, per-card reset, import/export with a five-step undo, presets, a shortcut recorder, one-click diagnostics, and a Privacy & network card listing every local read and outbound request.
- **First run and updates**: a setup wizard, a getting-started card that checks sign-in status and shows the login command, release notes after an update, "skip this version" and download progress.
- **Integrations**: `ai-usage-sidebar --print` for the Claude Code statusline, tmux or waybar (see [STATUSLINE](https://github.com/harveyxiacn/AI-usage-monitor-sidebar/blob/main/docs/STATUSLINE.md)); backup and restore; a command palette (Ctrl/Cmd+K); a shareable usage card image.
- **Providers and forecasts**: experimental OpenRouter support (not verified against a live account, off by default, key read from an environment variable only); token pace fills in when the quota percentage stalls.
- **Reliability**: the log watcher recovers when a log folder appears or is recreated; quota history is pruned and thinned by a retention setting; token expiry allows for clock skew and re-reads credentials; transient network errors are retried once.

Costs are API-price estimates, not subscription billing.
