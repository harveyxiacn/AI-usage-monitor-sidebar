# AI Usage Sidebar v0.7.0

## 中文

这一版的重点是"可信与收口"：让升级、降级和手动编辑设置都更安全，补齐多账号，把设置变得更易用，并在已有数据上给出建议。

- **升级更安全**：数据库升级前自动备份（保留最近 3 份），备份失败就不升级。以后旧版本也能打开只做了增量变更的新数据库；确需降级时可用 `ai-usage-sidebar --restore-pre-upgrade` 或 设置 → 备份与历史 中的"升级前备份"恢复。
- **设置文件更耐用**：带 BOM 的 UTF-8、PowerShell 写出的 UTF-16、内容为 `null` 或数组的文件都不会再把设置重置；无法读取的文件在被覆盖前会先备份为 `settings.json.bad-*`。
- **更少触发限流**：手动刷新也遵守 Claude 的 2 分钟最小间隔（间隔内显示缓存数据），上次请求时间（无论成败）写入磁盘，重启后同样生效。遇到 HTTP 429 时，日志会记下本应用最近 10 分钟发了几次请求——次数很少说明是同一账号的其他客户端（包括 Claude Code 本身）共享了额度。
- **设置更清爽**：分为"常用"和"高级"两层，默认只显示常用项（可见控件从 80 个减到 31 个）；搜索和命令面板仍能找到全部设置。两个早已废弃的重复键不再写入，旧文件照常读取。
- **多账号补齐**：额外账号现在也统计本地 token 历史，费用、预算、周报、订阅价值和会话都可按账号查看；诊断信息列出所有账号。macOS 上额外的 Claude 账号会尝试读取对应的钥匙串条目（命名规则来自社区工具，Anthropic 未公开文档，读取失败时显示为未登录）。
- **调度建议**：某个服务商快用完、另一个还有余量时，在概览和弹窗中提示"接下来这段时间可改用哪个"，附依据和置信度；可选开启通知。
- **套餐顾问**：根据撞上限次数、周期用量和订阅价值，建议升级、降级或保持（价格仅为参考）。
- **按提交统计成本**（需手动开启）：对已出现在用量记录中的项目目录读取 `git log` 的提交哈希、时间和标题（不读代码内容），按提交显示 token 与估算费用。
- **测试与发布**：CI 新增 Windows、macOS 启动冒烟测试，以及三平台"先装上一版再升级"的真实升级测试；发布流程已支持代码签名与 winget / Homebrew / Scoop / AUR 分发，待维护者配置证书和账号后启用。

费用均为按 API 价格的估算，不代表订阅账单。数据库结构升级到 v4（增量变更）；v0.6 及更早版本仍无法打开，降级前请使用升级前备份。

## English

This release is about trust: safer upgrades, downgrades and hand edits, finished multi-account support, simpler settings, and advice built on the data the app already has.

- **Safer upgrades**: the database is backed up before every schema upgrade (newest three kept), and the upgrade does not run if the backup fails. From now on an older version can still open a newer database when the change was additive; to go back, use `ai-usage-sidebar --restore-pre-upgrade` or Settings → Backup & history (backups from before database upgrades).
- **Sturdier settings file**: a UTF-8 file with a byte-order mark, UTF-16 from PowerShell, or a file that is `null` or an array no longer resets your settings, and an unreadable file is kept as `settings.json.bad-*` before anything overwrites it.
- **Fewer rate limits**: a manual refresh now keeps Claude's two-minute minimum interval (the cached value stays on screen), and the time of the last request, successful or not, is saved so a restart keeps it too. Every HTTP 429 is logged with how many requests this app sent in the last 10 minutes; a small number means another client on the same account (Claude Code itself included) shares the limit.
- **Simpler settings**: basic and advanced tiers, with only the basics shown by default (31 controls instead of 80). Search and the command palette still find everything. Two long-deprecated duplicate keys are no longer written; old files still load.
- **Multiple accounts, finished**: extra accounts now have local token history, so cost, budget, the weekly summary, subscription value and sessions work per account, and diagnostics list every account. On macOS an extra Claude account also tries its Keychain item (the naming rule comes from community tools; Anthropic does not document it, and a miss shows as "not signed in").
- **Routing advice**: when one provider is about to run out and another has room, Overview and the popover suggest which to use for the next while, with the numbers and confidence behind it. Notifications are optional.
- **Plan advisor**: upgrade, downgrade or keep, based on limit hits, cycle usage and subscription value (prices are hints).
- **Cost per commit** (opt-in): for project folders already in your usage log, reads `git log` hashes, times and subjects (never code) to show tokens and estimated cost per commit.
- **Testing and distribution**: CI now starts the app on Windows and macOS too, and runs a real "install the previous release, then upgrade" test on all three platforms. The release pipeline supports code signing and winget / Homebrew / Scoop / AUR, switched on once the maintainer adds certificates and accounts.

Costs are API-price estimates, not subscription billing. The database moves to schema v4 (an additive change); v0.6 and earlier still cannot open it, so use a pre-upgrade backup if you downgrade.
